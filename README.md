# Dart JSON Schema to Code Tool

This project is my Dart implementation of JSON Schema Tooling, more info [here](https://json-schema.org/tools?query=&sortBy=name&sortOrder=ascending&groupBy=toolingTypes&licenses=&languages=&drafts=&toolingTypes=&environments=&showObsolete=false&supportsBowtie=false#code-to-schema)

It accepts a valid JSON schema, it validates it, and finally writes on file a Typescript interface representation of it (Dart and more languages coming).

The goal is to be able to compile all [these](https://github.com/SchemaStore/schemastore) schemas successfully.
